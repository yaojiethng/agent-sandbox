# The design template

A design resolves trade-offs between options and recommends a decision. It opens during the iteration's design phase, and it closes into an ADR when it settles an implementation decision.

```markdown
# <Title>
**Status:** <draft | active | settled | superseded>

## Context
<what problem; what triggered the exploration>

## Options Considered
<alternatives with trade-offs; at least two>

## Decision
<the recommended approach and why>

## Consequences
<what this changes, enables, or forecloses>
```
