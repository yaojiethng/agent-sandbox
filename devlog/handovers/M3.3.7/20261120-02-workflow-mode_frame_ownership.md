# Handover - The mode frame has one owner

## Objective

Remove the four-mode frame from `principle-single-source-of-truth` and from `organization.md`, leaving each with the pointer it needs, so `communication-principle-organize-by-diataxis` is the frame's only statement.

## Scope

The row `Move the mode frame out of principle-single-source-of-truth and point organization.md at organize-by-diataxis`, which continues the split the row `The mode boundary is its own Diataxis skill` opened; that half landed at handover [20261116-17](20261116-17-impl-diataxis_card.md), and this iteration removes what the split left behind.

`organization.md` keeps what each mode is written like and which folder holds it here; retiring those per-mode paragraphs is out of scope, because they are the discipline the paragraph's reader needs and the frame does not state it.

The principle was restructured here on operator direction, beyond the row's wording: the row asked for the frame to leave, and the review found the principle had been stating the frame instead of the ruling that uses it. It now states one home per subject and dispatches three cases, one to `organize-by-diataxis` and one to `justify-materialization-cost`.

The marking rule landed here on operator direction after the pre-close gate read the body: the body had been written with a value out of a set as its predicate, and no principle answered that. It is one paragraph in `communication-principle-define-terminology-before-use`, beside the domain qualifier it belongs to.

The roadmap maintenance check found no state to promote: M3.3.7 is already `In progress`, and no completed sub-milestone reads as active.
