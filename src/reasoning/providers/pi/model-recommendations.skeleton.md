# Model recommendations

The container's copy of the role table, seeded when the project has none. The authority is `.agents/model-recommendations.md` in the project repository, and this file is replaced from that copy at every start when it exists.

One line per role. The role names are fixed; the operator sets the values.

Format: `_ROLE: <provider>/<model> at <thinking level>`

- A role line with no value is uninitialized, and the dispatch stops.
- Run the `setup-model-recommendations` skill to populate the lines.
