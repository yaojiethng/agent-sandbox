# Attach as You Read

Write so a reader who attaches each phrase as it arrives never holds material in memory or revises an expectation.

**The pattern.** The reader builds the sentence left to right. Give each phrase something already built to attach to.

| Instead of | Give |
|---|---|
| a passive that hides the actor | the actor in the subject slot |
| an imperative issued before the reader knows its object | the defined object first, then the imperative |
| a main clause split by the modifier it depends on | the main clause whole, the modifier after it |
| a condition long enough to bury the main clause | the main clause first, the condition after |
| a reading the reader must revise at the sentence end | the reading that holds from the first word |

**Why.** Comprehension is incremental and memory-limited. A hidden actor, an unanchored object, a split main clause, and a late reversal each spend the same limited memory, so the reader pays a cost the writer could have removed. Good-enough processing means a misread is silent rather than felt, so the cost arrives as a wrong instruction rather than a stumble.

**The test.** Read the sentence left to right. At each phrase, can it attach to structure already built? If the reader must hold a word for a later attachment, supply an antecedent the sentence never gives, or abandon an analysis already built, rewrite it.

**Where another rule wins.** A passive is correct when the agent is unknown or the patient is the topic. End-weight can put a heavy constituent first. A longer marked construction can beat a shorter garden path. A verbatim quote keeps its wording.
