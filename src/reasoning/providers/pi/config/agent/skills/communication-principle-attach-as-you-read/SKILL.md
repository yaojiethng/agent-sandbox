# Attach as you read

Give the reader something to attach each phrase to before the next phrase arrives.

**The pattern.** The reader builds the sentence left to right. Each phrase must find structure already built to attach to.

| Instead of | Give |
|---|---|
| a passive that hides the actor | the actor in the subject slot |
| an imperative issued before the reader knows its object | the object named first, then the imperative |
| a main clause split by the modifier it depends on | the main clause whole, the modifier after it |
| a condition long enough to bury the main clause | the main clause first, the condition after it |
| a reading the reader must revise at the sentence end | the reading that holds from the first word |

**Why.** Comprehension is incremental and memory-limited. A hidden actor, an unanchored object, a split main clause, and a late reversal each spend the same limited memory, so the reader pays a cost the writer could have removed. Good-enough processing means the reader stops at a plausible reading rather than the intended one, so a misread arrives as a wrong instruction rather than a stumble.

**Where another rule wins.** A passive is felicitous when the agent is unknown or the patient is the topic. End-weight puts the heavy constituent last, which can put a short condition first. A longer marked construction can beat a shorter garden path. A verbatim quote keeps its wording.

Where the word itself needs a definition, settle it first at `principle-define-terminology-before-use` at `$AGENT_HOME/agent/skills/principle-define-terminology-before-use/SKILL.md`, then place it here.

**The test.** Read the sentence left to right, and ask at each phrase whether it can attach to structure already built. Rewrite the sentence if the reader must do any of three things:

- hold a word for a later attachment,
- supply an antecedent the sentence never gives,
- abandon an analysis already built.
