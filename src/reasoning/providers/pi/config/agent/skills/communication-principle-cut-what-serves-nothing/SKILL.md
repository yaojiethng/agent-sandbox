# Cut what serves nothing

A document has one purpose, fixed by its Diataxis mode: a tutorial teaches, a how-to gets a job done, a reference is consulted, an explanation explains. A sentence that serves another mode's purpose belongs to the document of that mode. Here it is a second source for a job only that document maintains, so the two copies drift apart -- and it is attention spent on what the reader did not come for.

**The pattern.** Name the document's purpose, then test each sentence against it.

| Instead of | Give |
|---|---|
| an explanation inside a how-to | the step, and a pointer to the explanation |
| a how-to step inside a reference | the entry, and a pointer to the procedure |
| a rationale tail after an imperative | the imperative |
| a boundary the document already states | the one statement |
| an opener announcing what follows | the point |
| an instruction the reader already obeys by default | nothing |
| a sentence trimmed to a shorter form | the sentence cut whole |
| a term restated after it was defined | the term, once |

**Why.** The purpose is the test, and the two failures it catches are one: a sentence true anywhere serves no purpose, and a sentence serving another document's purpose is that document's, not this one's. Every sentence costs attention either way, and sediment is what settles when the test is not applied.

**Fires on.** A sentence the reader could drop and act the same, a sentence cut short where it could go, and a sentence that serves a neighbouring mode.

**What stays.** A guard changes no step and still bears, so the action test does not reach it: ask what wrongly proceeds without the line. A precondition, a stop, an exit condition, a citation earns its place when its absence permits an error, and the price it costs is the error it prevents.

**After a removal pass.** Read the removed lines for an imperative -- `must`, `never`, `do not`, `stop`, `only`, `unless`, `require` -- and find each one in the text that remains. A rule cut with its rationale is this principle's own failure: the document reads shorter and now permits what it forbade, and nothing reports it.

**What it does not cover.** A sentence that serves the purpose but sits where the reader cannot use it: `communication-principle-single-train-of-thought`. A word carrying the wrong distinction: `communication-principle-maximize-conceptual-leverage`. Whether the document should hold this job at all: `principle-single-source-of-truth`.

**The test.** Name the document's mode. A sentence serving another mode is cut, with a pointer to the document that serves it. A sentence serving this one bears if the reader would act differently were it gone, or if its absence lets the reader wrongly proceed; if neither, cut it whole rather than trim it.
