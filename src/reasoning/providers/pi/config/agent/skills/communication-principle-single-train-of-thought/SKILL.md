# Keep to a single train of thought

Carry one line of reasoning through the document, and let each sentence advance it.

**The pattern.** State the line in one sentence before writing, then read the result against it. A sentence either advances that line or belongs elsewhere. A second line placed beside the first, in a parenthesis or a caveat, makes the reader hold both.

| Instead of | Give |
|---|---|
| a section that opens a second argument beside the first | the second argument in its own section or document |
| a parenthesis that introduces a new subject | the new subject where it belongs |
| a caveat that changes the direction of the argument | the caveat stated first, then one argument |
| a detour that returns to the point | the point, without the detour |
| a summary that adds a claim the body never made | a summary of what the body argued |

**Why.** A detour costs the reader the place they were keeping, and the cost falls on the whole document, because the reader can no longer check the parts against one shape. A task with two goals, or a criterion that answers a different question from the one asked, carries the same fault.

**The test.** After each sentence, ask whether it advances the line the previous sentence was on. A sentence that opens a new line either closes the previous one or belongs in another document.
