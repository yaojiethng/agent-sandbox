# Cut what carries nothing

Keep the sentence that changes a decision, and delete the sentence that does not.

**The pattern.** Test each sentence against the reader's next action. When the test removes it, the sentence is gone.

| Instead of | Give |
|---|---|
| a sentence a reader can delete without losing the meaning | the sentence that remains |
| an empty opener ("it is worth noting that") | the point |
| an instruction the reader already obeys by default | nothing |
| a sentence trimmed to a shorter form | the sentence deleted whole |
| content kept because removing it feels risky | each line tested for bearing on the work |
| a term restated after it was defined | the term, once |

**Why.** Every sentence costs the reader attention whether or not it changes an action. A sentence that changes nothing pays that cost and returns nothing. Deleting it also keeps the document short enough that its live lines stay visible, because a long document thins attention across the excess.

**The test.** Ask of each sentence: would the reader act differently if it were gone? If no, delete it whole. Do not trim it. Then ask whether the document still says everything the reader needs.
