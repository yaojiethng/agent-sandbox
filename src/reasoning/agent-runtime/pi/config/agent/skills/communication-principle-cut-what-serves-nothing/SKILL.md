# Cut what serves nothing

A document has one purpose, fixed by its Diataxis mode: a tutorial teaches, a how-to gets a job done, a reference is consulted, an explanation explains. A sentence that serves another mode's purpose belongs to the document of that mode. Here it is a second source for a job only that document maintains, so the two copies drift apart -- and it is attention spent on what the reader did not come for.

**The pattern.** Name the document's purpose, then test each sentence against it.

| Instead of | Give |
|---|---|
| an explanation inside a how-to | the step, and a pointer to the explanation |
| a how-to step inside a reference | the entry, and a pointer to the procedure |
| a rationale tail after an imperative | the imperative |
| a boundary the document already states | the one statement |
| an opener announcing what follows, and a restatement after it | the point, once |
| an instruction the reader already obeys by default | nothing |
| a sentence trimmed to a shorter form | the sentence cut whole |
| a term restated after it was defined | the term, once |

**Why.** The purpose is the test, and the two failures it catches are one: a sentence true anywhere serves no purpose, and a sentence serving another document's purpose is that document's, not this one's. Sediment is what settles when the test is not applied.

**The ladder.** A passage written to present a claim rather than to decide one spends three sentences where one would do: an announcement, the claim, and a restatement. Each rung passes a sentence-level test, because each reads as content, so judge the passage rather than the sentence. Williams calls what the rungs are made of metadiscourse: prose that talks about the prose.

- A first sentence whose subject is this document, this section, this record or the table announces instead of stating: give the first sentence the subject.
- A general claim standing before the sentence that carries the fact, the number or the name supports nothing: fold it into that sentence.
- A closing sentence holding no fact the earlier ones lacked goes.
- Two sentences earn their place in a passage: a pointer naming a document the reader must open, and a guard stopping a wrong move. A rephrasing of the claim is neither.

An abstract is the ladder's surviving form: three sentences saying what the document is, what it covers, and why it exists. Open with the first fact instead.

**Fires on.** A passage whose first or last sentence can go with no loss to a reader who acts on it, a sentence cut short where it could go, and a sentence that serves a neighbouring mode.

**What stays.** A guard changes no step and still bears, so the action test does not reach it: ask what wrongly proceeds without the line. A precondition, a stop, an exit condition, a citation earns its place when its absence permits an error, and the price it costs is the error it prevents.

**After a removal pass.** Read the removed lines for an imperative -- `must`, `never`, `do not`, `stop`, `only`, `unless`, `require` -- and find each one in the text that remains. A rule cut with its rationale is this principle's own failure: the document reads shorter and now permits what it forbade, and nothing reports it.

**What it does not cover.** A sentence that serves the purpose but sits where the reader cannot use it: `communication-principle-single-train-of-thought`. A word carrying the wrong distinction: `communication-principle-maximize-conceptual-leverage`. Whether the document should hold this job at all: `principle-single-source-of-truth`.

**The test.** Name the document's mode. A sentence serving another mode is cut, with a pointer to the document that serves it. A sentence serving this one bears if the reader would act differently were it gone, or if its absence lets the reader wrongly proceed; if neither, cut it whole rather than trim it. A passage is a ladder when its first or last sentence can go without loss.
