# Cut metadiscourse

A sentence whose subject is the text itself says what the text already says, so it goes.

**The tidying principle.** The rule runs on the flow, the prose between the headings, not on the signpost. Metadiscourse in the flow is cut unless the deletion costs the reader something. The loss is open: a fact, a step, a definition, a relation, a target, a guard or a real hedge. If none goes, the deletion stands. A maxim before its support has the world as its subject and still goes, because the sentence after it carries the fact, the number or the name.

**Why.** Working memory is limited and attention is scarce. Maintain content density to engage the reader. Buried content does not register and burns attention.

**Acceptable patterns.** The cost of metadiscourse is only worth paying at the grain where the reader would otherwise lose the thread.

| Grain | What holds the thread |
|---|---|
| document | the abstract |
| paragraph | the topic sentence |
| sentence | the guard, and the claim itself |

**Cut every word that does no work.** If the sentence survives without a word, the word goes. "In order to" is "to". "It is important to note that" is nothing.

**Never "simply", "easy", or "quickly" in a procedure.** Avoid letting subjective judgement pollute prose. If it were simple, the reader would not be here.

**The test.** Delete the sentence. Read the passage without it. Restore it only if the reader loses one of the claims above. If none goes, the deletion stands. Cut whole, not trim. Run the test on the flow, not on the signpost.
