# Cut metadiscourse

A sentence in the flow that can be deleted without loss is metadiscourse, and it is cut whole.

**The tidying principle.** The rule runs on the flow, the prose between the headings, not on the signpost. Metadiscourse in the flow is cut unless the deletion costs the reader something. The loss is open: a fact, a step, a definition, a relation, a target, a guard or a real hedge. If none goes, the deletion stands.

**Why.** Working memory is limited and attention is scarce. Maintain content density to engage the reader. Buried content does not register and burns attention.

**Acceptable patterns.** The cost of metadiscourse is only worth paying at the grain where the reader would otherwise lose the thread.

| Grain | What holds the thread |
|---|---|
| document | the abstract |
| paragraph | the topic sentence |
| sentence | the guard, and the claim itself |

**Antipatterns.** Three shapes make metadiscourse likely. They are places to look, not verdicts.

- **The announce-restate frame.** The passage says what it will say, says it, then says what it said. This is the five-paragraph essay's introduction and conclusion applied to a document that is not an essay.
- **The buried lede.** The fact arrives after a wind-up, a definition or a general claim. The first sentence is not the point.
- **The maxim before the support.** A general claim stands before the sentence that carries the fact, the number or the name. The maxim adds nothing the support does not carry.

**The test.** Delete the sentence. Read the passage without it. Restore it only if the reader loses one of the things above. If none goes, the deletion stands. Cut whole, not trim. Run the test on the flow, not on the signpost.

**What it does not cover.** Which mode a unit serves: `communication-principle-organize-by-diataxis`. A sentence that serves its mode but sits where the reader cannot use it: `communication-principle-single-train-of-thought`. A second copy of one unit: `principle-single-source-of-truth`.
