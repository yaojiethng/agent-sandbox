# One addressing axis

A numbered list asserts a relation between its items. A bullet asserts none, so incur the stronger claim only where it holds.

**The pattern.** The relation is order, or addressability. Where neither holds, the number misleads twice. It implies an order that is not there, and it invites a reply the writer cannot place.

| Instead of | Give |
|---|---|
| a numbered list of items with no order | bullets |
| a bulleted procedure, where the steps run in sequence | a numbered list |
| a review's numbered findings beside lettered option choices | one axis, or "finding 1" beside "option A" |
| "option 2" where the page carries two numbered sets | the axis named, for example "option B" |
| a roadmap task named by its chat item number | a descriptive name |
| a section referenced as "item 3 of the other document" | the section, named |

**Why.** The operator answers with one short token, so a reply has to land on the item meant. Two unnamed axes give one token two readings, and the agent then guesses which set the answer addressed. A number also asserts an order the reader will act on, so a numbered list of unranked options reads as a ranking.

**Where a number earns its place.** Order matters, or a reader addresses an item by index. Which unit takes a number and which takes an identity code, the chat token form, and how a chat pick reaches a record belong to the project's numbering convention, where the project states one. This skill states the judgement; the scheme is the project's.

**Where several sets appear together.** Print one axis. Where two sets must appear, name each, so a reply is self-mapping: "finding 1" and "option A".

**Where the list is gone.** A number means nothing without the list that defined it. A durable artifact -- a roadmap task, a code comment, a record -- takes a descriptive name, never a number carried out of a transient list.

**Where many references land on one item.** Move the item to a heading, so the references point at a name rather than a position.

**The test.** Count the axes in the presentation. More than one, and a reader can answer into the wrong set, so name each. Then read each numbered list and ask whether the order holds or a reader cites a position. Where neither does, the number claims what the text cannot support, and the list is bullets.
