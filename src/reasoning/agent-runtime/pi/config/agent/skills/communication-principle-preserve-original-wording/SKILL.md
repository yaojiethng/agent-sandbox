# Preserve the original wording

An edit keeps the original wording, as the author left it: the phrasing, the cadence, the syntax and the structure. It fixes a minor mistake in place, and it raises a disagreement.

**Minor mistakes.** A typo, spelling, punctuation, broken grammar, broken markup, and the smallest reflow the correction needs. An edit fixes these in place.

**The wording.** It stays as written. The author's reasons for a wording are not in the text, so a rewrite of that wording is made without them.

**Asked for by the author.** A section the editor proposed and the author accepted, and output the author asked to include, become the author's wording.

**Disagreements.** Everything that is not a minor mistake is a disagreement, a factual error included. A disagreement is raised, not applied:

1. Quote the clause as it stands.
2. State what the clause requires.
3. Show the evidence, as far as it exists: the fact, the source, the clause it conflicts with, or the reading it produces.
4. Show the edit beside the clause, marked as a proposal.
5. Wait for the review. The edit stands when the author accepts it.

A term that names another concept, a condition that does not match the case it covers, a misspelling inside a protected word, an ambiguity the editor can resolve and the author has not, and a clause the evidence contradicts are each a disagreement.

**The test.** Read the edit aloud against the author's text. The same words stand in the same order and the same structure, apart from the minor mistakes fixed. Where the wording differs, the author's phrasing goes back. If the edit reads more formal, more generic or more like generated text than the original, the author's phrasing goes back. A change to a quantifier, a modal, a negation, a connector, a term, an actor, a condition or an exception is a disagreement.

**What it does not cover.** Where the text sits: [`principle-single-source-of-truth`](../principle-single-source-of-truth/SKILL.md). Whether a session-private referent survives: [`communication-principle-write-for-the-reader`](../communication-principle-write-for-the-reader/SKILL.md).
